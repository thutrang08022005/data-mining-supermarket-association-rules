\# Data Mining - Supermarket Association Rules



This repository contains the source code and notebooks for the supermarket association rules mining project.



\## Project structure



\- `app/app.py`: Main application/source code.

\- `notebooks/`: Jupyter notebooks for data checking, frequent itemset mining, association rule analysis, and deep analysis.

\- `.gitignore`: Used to exclude large datasets and generated result files.



\## Note about dataset and results



The `data/` folder is not included in this repository because the dataset files are too large for GitHub upload.



The `result/` folder is also not included because it contains generated output files after running the source code.



To run this project, please prepare the required dataset locally before executing the notebooks/source code.
